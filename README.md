# Голос → Текст — сайт для транскрибации аудио

Готовый минималистичный веб-сервис на русском языке. Пользователь выбирает аудиофайл, отправляет его серверу и получает распознанный текст, который можно редактировать, копировать и скачивать как TXT.

## Запуск локально

Требуется Node.js 20 или новее и API-ключ OpenAI с доступом к аудиотранскрибации.

1. Установите зависимости: `npm install`
2. Скопируйте `.env.example` в `.env`.
3. Впишите ключ в `.env`: `OPENAI_API_KEY=...`
4. Запустите: `npm start`
5. Откройте `http://localhost:3000`

## Публикация

Разверните проект на Node.js-хостинге, который поддерживает HTTPS и переменные окружения. Задайте `OPENAI_API_KEY` в настройках хостинга. Не публикуйте `.env` и не вставляйте API-ключ в HTML/JavaScript браузера.

## Важные ограничения

- Максимальный размер одного файла — 25 МБ.
- Поддерживаются MP3, MP4, MPEG, MPGA, M4A, WAV и WEBM.
- Можно выбрать русский или английский язык; режим автоопределения использует автоматический выбор модели.
- Для файлов длиннее лимита потребуется добавить разбиение на фрагменты.
- Сервис удаляет временный файл после обработки, но для публичного использования дополнительно настройте авторизацию, лимиты запросов, HTTPS, политику хранения данных и защиту от злоупотреблений.
- Не загружайте медицинские или другие конфиденциальные записи на непроверенный хостинг. Учитывайте согласие участников и требования к персональным данным.
